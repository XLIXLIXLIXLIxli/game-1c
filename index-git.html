    ☁️ Сохранение на GitHub
    Как получить токен (2 минуты)
    1. GitHub → аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Срок — хоть «No expiration». Repository access → Only select repositories → выбери этот репозиторий.
    3. Permissions → Contents → Read and write. Больше ничего не нужно.
    4. Скопируй токен и вставь сюда. Он хранится только в этом браузере и даёт доступ только к одному репозиторию.
